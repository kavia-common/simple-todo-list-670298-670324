# simple-todo-list-670298-670324

A modern, single-page Todo application frontend built with React, themed using the Ocean Professional palette.

Project structure:
- todo_app_frontend: React app (Create React App)

How to run the frontend:
1) cd todo_app_frontend
2) npm install
3) npm start

The app will be available at:
http://localhost:3000

Features:
- Add todos using the input and Add button or press Enter
- Toggle completion via checkbox
- Delete todos with the delete button
- Persist todos in browser localStorage
- Ocean Professional theme: rounded corners, subtle shadows, gradient header, smooth transitions
